# 知客 AI 销售助手 MVP

## 产品定位

面向 5-10 人中小教培团队，在小红书私信和微信聊天旁提供销售辅助：

1. 读取当前可见对话，不自动发送。
2. 识别客户意图、购买意向、核心诉求和当前异议。
3. 结合课程知识库生成三条差异化候选话术。
4. 本地拦截高风险教育营销表达。
5. 由销售选择、修改并手动发送。
6. 管理客户来源、线索阶段、意向等级和下一步动作。
7. 基于真实课程资料生成公域内容，并在输出前执行合规检查。

## 当前链路

```text
小红书 / 微信
    -> 无障碍节点读取
    -> 读不到时本地 OCR
    -> 联系人、课程资料、历史上下文
    -> 客户意图与购买意向判断
    -> 生成 3 条销售话术
    -> 本地合规拦截
    -> 匹配度排序
    -> 悬浮窗复制或填入
    -> 销售人工确认发送
```

## 销售工作台

- 首页展示客户线索、高意向、待跟进三个关键指标。
- 指标可直接进入对应线索筛选，首页展示最多 3 个优先跟进客户。
- 跟进支持结构化日期，首页区分今日待办与逾期任务。
- 客户线索支持 `新线索 / 已沟通 / 已试听 / 待成交 / 已成交 / 暂缓` 阶段。
- 意向等级支持 `高 / 中 / 低 / 待判断`。
- 线索支持关键词搜索，并可快速完成本次跟进。
- 下一步动作记录明确的负责人动作与时间，形成从私信识别到人工跟进的闭环。
- 公域内容工坊支持平台、内容类型和常用场景选择，并记忆未完成草稿。
- 未提供的课程事实不得由模型补全；生成过程中按钮锁定，避免重复请求。

## 判断标签

- 客户意图：需求探索、价格咨询、方案对比、信任验证、异议处理、准备转化。
- 购买意向：1-5 级，仅依据对话中的明确行为信号。
- 核心诉求：需求澄清、价值匹配、可信证据、价格、时间、具体服务。
- 下一步动作：追问需求、回答事实、提供材料、处理异议、邀请测评/试听、征得同意后承接、约定跟进。

## 建议知识库

每个课程或业务线至少维护以下笔记，并使用稳定标签：

| 笔记 | 必填内容 | 建议标签 |
|---|---|---|
| 课程产品 | 适合人群、目标、课时、形式、服务边界 | 年级、学科、课程名 |
| 价格政策 | 标准价、有效优惠、退款规则、有效期 | 价格、优惠、退款 |
| 师资信息 | 可公开履历、授课特点，不写无法核实的头衔 | 老师、师资 |
| 咨询 SOP | 首轮问题、意向分级、跟进节奏、转化条件 | 咨询、跟进 |
| 合规边界 | 禁用承诺、敏感词、平台导流规则 | 合规、禁用 |
| 常见异议 | 价格、时间、效果、孩子抵触等标准处理方式 | 异议 |

知识库只能提供已审核事实。模型不得自行补全价格、效果、师资、案例或优惠。

## 本地合规规则

`ComplianceGuard` 当前拦截：

- 包过、保过、包录取、保证提分等结果承诺。
- 百分之百有效、全国第一、最权威等绝对化宣传。
- 内部原题、押中原题、命题组内部等考试违规暗示。
- 保证赚钱、稳赚不赔等收益承诺。
- 最后一个名额、仅剩名额等高风险虚假稀缺表达。

提示词不能保证零违规，因此候选生成后和填入前各检查一次。生产环境仍应保留人工确认，并由法务或业务负责人维护规则库。

## 小红书适配验证

小红书版本更新可能改变无障碍节点。上线前需在目标手机和目标版本执行：

1. 打开真实私信会话，使用 `adb shell uiautomator dump` 导出节点树。
2. 确认聊天输入框的 `resource-id`、`hint` 或 `content-desc`。
3. 确认消息正文是否是可读叶子节点，以及左右气泡坐标。
4. 验证会话列表、搜索页不会被误判为聊天页。
5. 分别验证文字、图片、卡片、系统通知和长消息。
6. 节点不可读时验证 OCR 截屏权限、识别结果和限频逻辑。

当前 `XiaohongshuAdapter` 是语义与几何规则的保守基线，尚不能替代目标版本真机验收。

## MVP 验收标准

- 微信原有读取与填入链路无回归。
- 小红书私信可正确识别会话页，读取最近消息或进入 OCR 兜底。
- 新消息触发后展示意向等级、客户意图、诉求和下一步动作。
- 始终输出三条候选话术，不安全候选被安全话术替换。
- 高风险话术无法通过“填入”进入聊天输入框。
- 应用不自动点击发送，不自动加好友，不自动跨平台导流。
